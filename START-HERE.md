# Start Here

In VS Code, open this project folder and run:

```bash
npm run check
npm test
npm run dev
```

Then open:

```text
http://localhost:4173
```

For the full public site, push the repository to GitHub and import it into Vercel. Set `SITE_URL` and `ALLOWED_ORIGINS` before the production deployment. See `README.md` for Search Console and AdSense environment variables.
