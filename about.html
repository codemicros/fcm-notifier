About FCM Notification Tester

FCM Notification Tester is a focused developer utility for quickly testing Firebase Cloud Messaging notifications without a temporary script or Postman collection.

Why this tool exists

FCM testing should be quick. FCM Notification Tester keeps the interface intentionally small: Firebase service account JSON, device token, title, message, optional data, and one send button.

Built for the current FCM API

The send flow uses Firebase Cloud Messaging HTTP v1 authorization rather than the retired legacy static server-key endpoint.

Independence

FCM Notification Tester is an independent developer tool and is not affiliated with, endorsed by, or sponsored by Google or Firebase.
